# Phase 3: MCP Server and Wiki Hand-off Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Claude Code (and Codex, Cursor) session on this Mac can list projects and meetings, read transcripts, and move or retitle a meeting through four `meetily` MCP tools, so the three wikis stop symlinking the recordings folder.

**Architecture:** A standalone stdio MCP server in a new top-level `mcp/` package, run directly by Node 26 from TypeScript (no build step). It reads and writes the recordings root on disk only; it never touches SQLite. The app's reconcile (Phase 2) picks up moves and renames on the next sidebar refresh for v2 folders. Legacy flat folders are served under project `_inbox`, with `transcript.md` rendered on the fly from `transcripts.json`. The server is registered once at user scope for Claude Code, plus equivalent entries for Codex and Cursor. Each wiki gets a one-paragraph skill change; the recruiting matcher script reads the root directly.

**Tech Stack:** Node 26 (type stripping, `node --test`), TypeScript (erasable syntax only), `@modelcontextprotocol/sdk@1.32.1`, `zod@4.6.6`, npm for the package (not pnpm).

Spec: `docs/superpowers/specs/2026-10-27-personal-meeting-recorder-design.md`, sections 4.6, 5.3, 5.4. Phase 2 contracts (folder layout, metadata v2, transcript.md) are the inputs; see `frontend/src-tauri/src/audio/library.rs` and `transcript_md.rs` for the Rust reference behaviour this server mirrors.

## Global Constraints

- The server is filesystem-only. It must work with the app closed. It never writes SQLite.
- Root is `MEETILY_RECORDINGS` when set, else `~/Movies/meetily-recordings`.
- Legacy flat folders (metadata without a string `meeting_id`, at the root) are listed as project `_inbox`, are never moved by a title change, and have their transcript rendered from `transcripts.json` in the spec 5.3 format.
- Folder naming mirrors Rust `library.rs`: stamp `YYYY-MM-DD_HH-MM` (local), slug appended only for non-auto titles, collisions get `-2`, `-3`; project names are single normal path components (not empty, not `.` or `..`, no `/`, `\`, NUL, no leading dot); `_inbox` is listed first.
- Tool contract is spec 5.4 verbatim: `list_projects`, `list_meetings({project?, since?, until?, limit?=20})`, `get_transcript({meeting_id?, path?, format?="md"|"text"|"json", start_seconds?, end_seconds?})`, `assign_meeting({meeting_id, project?, title?})`. `quality` values: `live`, `enhanced`, `enhancing` (covers queued and running), `failed`. Errors are returned as MCP tool errors with a plain message.
- TypeScript must stay within Node's erasable syntax: `type` aliases, `import type`, no `enum`, no parameter properties, no namespaces; relative imports carry the `.ts` extension.
- Dependencies pinned exactly: `@modelcontextprotocol/sdk` `1.32.1`, `zod` `4.6.6`. Install with `npm install` inside `mcp/`; never run `pnpm` here. `mcp/node_modules/` is git-ignored.
- Tests: `cd mcp && node --test test/` on a temp fixture root. Nothing in this phase touches the Rust crate or the Next.js app.
- No em-dashes in any text, code comment or string.
- Wiki edits (Tasks 5) are made with native file tools on skill files and scripts only (they live outside the OpenKnowledge index), are left uncommitted in those repositories for the owner to review, and never delete the symlinks; the owner does that after acceptance.
- Branch `phase-3/mcp`, one commit per task, no push.

```ts
import os from 'node:os';
import path from 'node:path';

export const INBOX = '_inbox';

const AUTO_TITLE = /^Meeting (\d{2}_\d{2}_\d{2}_\d{2}_\d{2}_\d{2}|\d{4}-\d{2}-\d{2}_\d{2}-\d{2}-\d{2})$/;
const STAMP_PREFIX = /^\d{4}-\d{2}-\d{2}_\d{2}-\d{2}/;

/** MEETILY_RECORDINGS or ~/Movies/meetily-recordings. */
export function recordingsRoot(): string {
  return process.env.MEETILY_RECORDINGS || path.join(os.homedir(), 'Movies', 'meetily-recordings');
}

export function isValidProjectName(name: string): boolean {
  const n = name.trim();
  return n.length > 0 && n !== '.' && n !== '..' && !n.startsWith('.') && !n.includes('/') && !n.includes('\\') && !n.includes('\0');
}

export function slug(title: string): string {
  let out = '';
  let lastDash = true;
  for (const c of title) {
    if (/[A-Za-z0-9]/.test(c)) { out += c.toLowerCase(); lastDash = false; }
    else if (!lastDash) { out += '-'; lastDash = true; }
    if (out.length >= 60) break;
  }
  return out.replace(/^-+|-+$/g, '');
}

export function isAutoTitle(title: string): boolean {
  return AUTO_TITLE.test(title.trim());
}

const pad = (n: number) => String(n).padStart(2, '0');

export function localStamp(date: Date): string {
  return `${date.getFullYear()}-${pad(date.getMonth() + 1)}-${pad(date.getDate())}_${pad(date.getHours())}-${pad(date.getMinutes())}`;
}

export function stampOfFolder(name: string): string | null {
  const m = STAMP_PREFIX.exec(name);
  return m ? m[0] : null;
}

export function meetingFolderName(stamp: string, title?: string | null): string {
  const s = title && !isAutoTitle(title) ? slug(title) : '';
  return s ? `${stamp} ${s}` : stamp;
}

export function formatMmss(seconds: number): string {
  const total = Math.floor(Math.max(0, seconds || 0));
  return `${pad(Math.floor(total / 60))}:${pad(total % 60)}`;
}

/** RFC 3339 in UTC rendered in local time with an explicit offset; garbage passes through. */
export function toLocalIso(rfc3339: string): string {
  const d = new Date(rfc3339);
  if (Number.isNaN(d.getTime())) return rfc3339;
  const offsetMin = -d.getTimezoneOffset();
  const sign = offsetMin >= 0 ? '+' : '-';
  const abs = Math.abs(offsetMin);
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}T${pad(d.getHours())}:${pad(d.getMinutes())}:${pad(d.getSeconds())}${sign}${pad(Math.floor(abs / 60))}:${pad(abs % 60)}`;
}
```

Note that `formatMmss` does not wrap minutes at 60, matching the Rust renderer. If the `slug` 60-cap test fails by one because of a trailing dash, cap before trimming as the Rust version does: the expected value stays 60.

```ts
import fs from 'node:fs';
import path from 'node:path';
import {
  INBOX, isValidProjectName, localStamp, stampOfFolder, meetingFolderName, formatMmss, toLocalIso,
} from './paths.ts';

export type Quality = 'live' | 'enhanced' | 'enhancing' | 'failed';

export type MeetingInfo = {
  meeting_id: string | null;
  project: string;
  title: string;
  started_at: string;
  duration_seconds: number | null;
  quality: Quality;
  path: string;
  legacy: boolean;
};

type Json = Record<string, unknown>;

function readJson(file: string): Json | null {
  try { return JSON.parse(fs.readFileSync(file, 'utf8')) as Json; } catch { return null; }
}

function writeJsonAtomic(file: string, value: unknown): void {
  const tmp = path.join(path.dirname(file), '.metadata.json.tmp');
  fs.writeFileSync(tmp, JSON.stringify(value, null, 2));
  fs.renameSync(tmp, file);
}

function isDir(p: string): boolean {
  try { return fs.statSync(p).isDirectory(); } catch { return false; }
}

function hasMetadata(dir: string): boolean {
  return fs.existsSync(path.join(dir, 'metadata.json'));
}

/** Project folders: not hidden, no metadata.json. Inbox first, then sorted. */
export function listProjects(root: string): string[] {
  let names: string[] = [];
  try {
    names = fs.readdirSync(root)
      .filter((n) => !n.startsWith('.') && n !== INBOX && isDir(path.join(root, n)) && !hasMetadata(path.join(root, n)))
      .sort((a, b) => a.localeCompare(b));
  } catch { /* missing root: only the inbox */ }
  return [INBOX, ...names];
}

function qualityOf(meta: Json): Quality {
  const enhanced = (meta.transcription as Json | undefined)?.enhanced as Json | undefined;
  const status = enhanced?.status;
  if (status === 'done') return 'enhanced';
  if (status === 'running' || status === 'queued') return 'enhancing';
  if (status === 'failed') return 'failed';
  return meta.retranscribed_at ? 'enhanced' : 'live';
}

function infoFrom(root: string, dir: string, legacy: boolean): MeetingInfo | null {
  const meta = readJson(path.join(dir, 'metadata.json'));
  if (!meta) return null;
  const id = typeof meta.meeting_id === 'string' && meta.meeting_id ? meta.meeting_id : null;
  const title = (typeof meta.title === 'string' && meta.title.trim()) ? meta.title
    : (typeof meta.meeting_name === 'string' && meta.meeting_name.trim()) ? meta.meeting_name
    : path.basename(dir);
  const project = legacy ? INBOX : path.basename(path.dirname(dir));
  return {
    meeting_id: id,
    project,
    title,
    started_at: typeof meta.created_at === 'string' ? meta.created_at : '',
    duration_seconds: typeof meta.duration_seconds === 'number' ? meta.duration_seconds : null,
    quality: qualityOf(meta),
    path: dir,
    legacy,
  };
}

/** Every meeting under the root: <root>/<project>/<meeting>/ plus legacy <root>/<meeting>/. Newest first. */
export function scanMeetings(root: string): MeetingInfo[] {
  const out: MeetingInfo[] = [];
  let entries: string[] = [];
  try { entries = fs.readdirSync(root); } catch { return out; }
  for (const name of entries) {
    if (name.startsWith('.')) continue;
    const dir = path.join(root, name);
    if (!isDir(dir)) continue;
    if (hasMetadata(dir)) {
      const info = infoFrom(root, dir, true);
      if (info) out.push(info);
      continue;
    }
    for (const sub of fs.readdirSync(dir)) {
      const meetingDir = path.join(dir, sub);
      if (sub.startsWith('.') || !isDir(meetingDir) || !hasMetadata(meetingDir)) continue;
      const info = infoFrom(root, meetingDir, false);
      if (info) out.push(info);
    }
  }
  return out.sort((a, b) => b.started_at.localeCompare(a.started_at));
}

export function findMeeting(root: string, ref: { meeting_id?: string; path?: string }): MeetingInfo | null {
  const all = scanMeetings(root);
  if (ref.meeting_id) return all.find((m) => m.meeting_id === ref.meeting_id) ?? null;
  if (ref.path) {
    const wanted = path.resolve(ref.path);
    return all.find((m) => path.resolve(m.path) === wanted) ?? all.find((m) => path.basename(m.path) === ref.path) ?? null;
  }
  return null;
}

type Segment = { start: number; text: string; raw: Json };

function readSegments(info: MeetingInfo): Segment[] {
  const data = readJson(path.join(info.path, 'transcripts.json'));
  const list = Array.isArray(data?.segments) ? (data!.segments as Json[]) : [];
  return list
    .map((s) => ({ start: Number(s.audio_start_time ?? 0), text: String(s.text ?? ''), raw: s, seq: Number(s.sequence_id ?? 0) }))
    .sort((a, b) => a.seq - b.seq);
}

function yamlString(s: string): string {
  return `"${s.replace(/\\/g, '\\\\').replace(/"/g, '\\"')}"`;
}

/** spec 5.3, same bytes as the Rust renderer. */
export function renderTranscriptMd(info: MeetingInfo, model: string, segments: Array<{ start: number; text: string }>): string {
  let out = '---\n';
  out += `title: ${yamlString(info.title)}\n`;
  out += `project: ${info.project}\n`;
  out += `meeting_id: ${info.meeting_id ?? ''}\n`;
  out += `started_at: ${toLocalIso(info.started_at)}\n`;
  if (info.duration_seconds !== null) out += `duration_seconds: ${Math.round(info.duration_seconds)}\n`;
  out += `quality: ${info.quality}\n`;
  out += `model: ${model}\n`;
  out += '---\n';
  for (const s of segments) {
    const line = s.text.split(/\s+/).filter(Boolean).join(' ');
    if (!line) continue;
    out += `[${formatMmss(s.start)}] ${line}\n`;
  }
  return out;
}

function inRange(start: number, from?: number, to?: number): boolean {
  return (from === undefined || start >= from) && (to === undefined || start <= to);
}

export function readTranscript(info: MeetingInfo, format: 'md' | 'text' | 'json', startSeconds?: number, endSeconds?: number): string {
  const ranged = startSeconds !== undefined || endSeconds !== undefined;
  const mdPath = path.join(info.path, 'transcript.md');
  if (format === 'md' && !ranged && fs.existsSync(mdPath)) return fs.readFileSync(mdPath, 'utf8');
  const segments = readSegments(info).filter((s) => inRange(s.start, startSeconds, endSeconds));
  if (format === 'json') return JSON.stringify(segments.map((s) => s.raw), null, 2);
  if (format === 'text') return segments.map((s) => s.text.split(/\s+/).filter(Boolean).join(' ')).filter(Boolean).map((t) => `${t}\n`).join('');
  return renderTranscriptMd(info, 'unknown', segments);
}

/**
 * Move and/or retitle a meeting on disk. Mirrors the Rust `library::assign` rules without SQLite:
 * the stamp is kept, the title decides the slug, the project decides the parent, a legacy folder is
 * never moved by a title change, and a running enhance job blocks moves (title updates in place).
 */
export function assignMeeting(root: string, info: MeetingInfo, changes: { project?: string; title?: string }): string {
  if (changes.project !== undefined && !isValidProjectName(changes.project)) {
    throw new Error(`Invalid project name: ${changes.project}`);
  }
  const metaPath = path.join(info.path, 'metadata.json');
  const meta = readJson(metaPath);
  if (!meta) throw new Error(`metadata.json missing or unreadable at ${info.path}`);
  const newTitle = changes.title ?? info.title;
  const enhanced = (meta.transcription as Json | undefined)?.enhanced as Json | undefined;
  const running = enhanced?.status === 'running' || enhanced?.status === 'queued';
  const oldName = path.basename(info.path);
  const legacy = stampOfFolder(oldName) === null;

  const inPlace = () => {
    meta.title = newTitle;
    if (info.meeting_id) meta.meeting_id = info.meeting_id;
    writeJsonAtomic(metaPath, meta);
    return info.path;
  };

  if (running && changes.project !== undefined) throw new Error('This meeting is being enhanced right now. Try moving it when it finishes.');
  if (running) return inPlace();
  if (legacy && changes.project === undefined) return inPlace();

  const project = changes.project ?? info.project;
  const createdAt = typeof meta.created_at === 'string' ? new Date(meta.created_at) : new Date(NaN);
  const stamp = stampOfFolder(oldName) ?? localStamp(Number.isNaN(createdAt.getTime()) ? new Date() : createdAt);
  const base = meetingFolderName(stamp, newTitle);
  const projectDir = path.join(root, project);
  fs.mkdirSync(projectDir, { recursive: true });
  let target = path.join(projectDir, base);
  for (let n = 2; fs.existsSync(target) && path.resolve(target) !== path.resolve(info.path); n++) {
    target = path.join(projectDir, `${base}-${n}`);
  }
  if (path.resolve(target) !== path.resolve(info.path)) fs.renameSync(info.path, target);
  meta.project = project;
  meta.title = newTitle;
  if (info.meeting_id) meta.meeting_id = info.meeting_id;
  if (!meta.version) meta.version = '2.0';
  writeJsonAtomic(path.join(target, 'metadata.json'), meta);
  return target;
}
```

```ts
#!/usr/bin/env node
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { z } from 'zod';
import { recordingsRoot } from './paths.ts';
import { listProjects, scanMeetings, findMeeting, readTranscript, assignMeeting } from './library.ts';

const root = recordingsRoot();
const server = new McpServer({ name: 'meetily', version: '0.1.0' });

const text = (value: unknown) => ({ content: [{ type: 'text' as const, text: typeof value === 'string' ? value : JSON.stringify(value, null, 2) }] });
const fail = (message: string) => ({ isError: true as const, content: [{ type: 'text' as const, text: message }] });

server.registerTool(
  'list_projects',
  { description: `Project folders under the Meetily recordings root (${root}). "_inbox" holds untagged and legacy meetings.`, inputSchema: {} },
  async () => {
    const all = scanMeetings(root);
    return text(listProjects(root).map((name) => {
      const mine = all.filter((m) => m.project === name);
      return { name, meeting_count: mine.length, last_meeting_at: mine[0]?.started_at ?? null };
    }));
  },
);

server.registerTool(
  'list_meetings',
  {
    description: 'Meetings recorded by Meetily, newest first. Filter by project folder and/or ISO date range. quality is live, enhanced, enhancing or failed.',
    inputSchema: {
      project: z.string().optional().describe('Project folder name, e.g. "dex". "_inbox" for untagged and legacy meetings.'),
      since: z.string().optional().describe('ISO 8601 date or datetime; only meetings started at or after it.'),
      until: z.string().optional().describe('ISO 8601 date or datetime; only meetings started at or before it.'),
      limit: z.number().int().positive().max(200).default(20),
    },
  },
  async ({ project, since, until, limit }) => {
    const sinceT = since ? Date.parse(since) : undefined;
    const untilT = until ? Date.parse(until) : undefined;
    if ((since && Number.isNaN(sinceT)) || (until && Number.isNaN(untilT))) return fail('since/until must be ISO 8601 dates');
    const rows = scanMeetings(root).filter((m) => {
      if (project && m.project !== project) return false;
      const t = Date.parse(m.started_at);
      if (sinceT !== undefined && !(t >= sinceT)) return false;
      if (untilT !== undefined && !(t <= untilT)) return false;
      return true;
    }).slice(0, limit);
    return text(rows);
  },
);

server.registerTool(
  'get_transcript',
  {
    description: 'Transcript of one meeting. "md" is transcript.md (rendered from transcripts.json for legacy folders), "text" strips timestamps, "json" is the raw segments. Optional time range in seconds.',
    inputSchema: {
      meeting_id: z.string().optional(),
      path: z.string().optional().describe('Absolute folder path or folder name, when the meeting has no id (legacy).'),
      format: z.enum(['md', 'text', 'json']).default('md'),
      start_seconds: z.number().nonnegative().optional(),
      end_seconds: z.number().nonnegative().optional(),
    },
  },
  async ({ meeting_id, path: folder, format, start_seconds, end_seconds }) => {
    if (!meeting_id && !folder) return fail('Give meeting_id or path');
    const info = findMeeting(root, { meeting_id, path: folder });
    if (!info) return fail(`No meeting found for ${meeting_id ?? folder}`);
    if (info.quality === 'enhancing') return fail('Transcript is still being enhanced; try again in a few minutes or request format "json" for the live segments.');
    return text(readTranscript(info, format, start_seconds, end_seconds));
  },
);

server.registerTool(
  'assign_meeting',
  {
    description: 'Move a meeting to a project folder and/or set its title. Renames the folder; the Meetily app picks the change up on its next refresh. A legacy flat folder is only moved when a project is given.',
    inputSchema: {
      meeting_id: z.string().optional(),
      path: z.string().optional().describe('For legacy meetings without an id: absolute folder path or folder name.'),
      project: z.string().optional(),
      title: z.string().optional(),
    },
  },
  async ({ meeting_id, path: folder, project, title }) => {
    if (!meeting_id && !folder) return fail('Give meeting_id or path');
    if (project === undefined && title === undefined) return fail('Give project and/or title');
    const info = findMeeting(root, { meeting_id, path: folder });
    if (!info) return fail(`No meeting found for ${meeting_id ?? folder}`);
    try {
      return text({ path: assignMeeting(root, info, { project, title }) });
    } catch (error) {
      return fail(error instanceof Error ? error.message : String(error));
    }
  },
);

await server.connect(new StdioServerTransport());
```
